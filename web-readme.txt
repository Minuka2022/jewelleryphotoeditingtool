JEWELRY STUDIO - WEB VERSION
============================

START
  Double-click "Jewelry Studio.exe".
  A small black window opens and your browser opens the app.
  Keep the black window open while you work. Close it to stop.

  If the browser does not open by itself, go to the address shown in the
  black window (normally http://127.0.0.1:8787/).

  Windows may ask whether to allow the program: choose "Allow" or
  "More info" > "Run anyway". It only accepts connections from this computer.

FIRST TIME
  File > Settings: paste your Gemini API key. It is stored in the Windows
  Credential Manager, the same place the desktop app uses.

YOUR WORK
  Photos, generated images, crops and your own styles are kept in the "data"
  folder next to the program. Back that folder up to keep your work.
  On the very first start, your styles from the desktop app are copied in.

EXPORTING
  File > Export As saves through your browser's downloads: one image as a
  file, several images as one ZIP file.

UPDATING
  Close the black window, replace "Jewelry Studio.exe" with the new copy,
  and start it again. The "data" folder is kept.
